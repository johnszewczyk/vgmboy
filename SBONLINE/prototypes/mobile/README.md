# Mobile Interface Concept

`index.html` is a self-contained visual concept for the SBONLINE mobile
library. Its game and track rows are sample data; controls do not connect to a
catalog, account, or audio stream. Production source lives in
`SBONLINE/server/`; release packaging lives in `SBONLINE/ops/server/`.

The prototype and production app use five app pages: Playing, Library,
Gallery, Sound, and Options. Sound and Options are separate account-backed
settings pages in production. This prototype is for layout review only.
