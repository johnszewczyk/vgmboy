# Project Info

## Status

`SPCBoy/` is archived Electron source retained for recovery and historical
reference. It is not a maintained app, release target, or routine verification
target. Its current maintained siblings are CocoaSpice, SPCBoyWK, and ViewBoy.

## Preserved boundaries

This source snapshot contains the Electron host and renderer, its former
catalog/playlist integration, and old VGMBoy bridge adapters. The code and
focused notes under `ai/subsystem-human/` and `ai/subsystem-agent/` describe
only this archived implementation; do not treat them as active frontend
requirements.
