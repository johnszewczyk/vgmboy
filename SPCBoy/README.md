# SPCBoy (archived Electron source)

This directory preserves the legacy Electron SPCBoy implementation for
recovery and historical reference. It is not a maintained app or release target;
routine family verification does not build it. The maintained player frontends
are CocoaSpice, SPCBoyWK, and ViewBoy. Shared playback belongs to VGMBoy, and
shared catalog work belongs to ScanSong and CatalogReader.

The archived source retains the old Electron host, renderer, build scripts,
third-party notices, and focused implementation notes. Treat behavior
references under `ai/subsystem-human/` and `ai/subsystem-agent/` as descriptions
of this archived code, not requirements for active frontends.

For current recovery and local archive paths, see
[`../LocalRecovery/README.md`](../LocalRecovery/README.md). The current family
repo preserves this tree’s source and imported Git history.
