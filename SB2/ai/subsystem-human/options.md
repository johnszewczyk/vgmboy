# Options

- Options open as a subpage in the playlist pane.
- SPCBOY owns Database, Interface Chrome, Interface Fonts, and Windows settings. VGMBoy owns Playback,
  Routing, Audio, and Diagnostics settings; the navigation keeps these groups
  separate.
- Options pages use an open layout with thin section rules and a shared rem
  spacing scale. Interface Chrome and Interface Fonts are separate SPCBoy
  pages. The same subpage and title/footer chrome appear in the optional
  standalone Options window.
- Reload Library refreshes the read-only catalog projections used by the
  sidebar. ScanSong remains the catalog writer.
