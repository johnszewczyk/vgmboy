# VGMManDocs instructions

Read `ai/AGENTS.md`, then `ai/project-info.md`, then the focused human or
agent note routed by that file.

VGMManDocs is the VGMMan family's native Markdown documentation viewer and
editor. Published project Markdown belongs in `Docs/md/<SubAppName>/` and is
grouped there by its owning VGMMan component. Keep DocMan intake files,
engineering constraints, plans, reports, and verification records in their
required routed locations; they are not website content by default.

Run family Git commands from the VGMMan repository root. This app is a package
inside that repository, not a separate Git repository.
