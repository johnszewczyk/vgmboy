# VGMManDocs documentation routing

Read `../AGENTS.md`, then `project-info.md`, followed by the narrow note for
the task.

- `subsystem-human/` records behavior visible in VGMManDocs.
- `subsystem-agent/` records file ownership, rendering, bridge, and save rules.
- `../Docs/md/<SubAppName>/` is published Markdown content shown by the app.
- Keep agent instructions and engineering notes out of published content.
