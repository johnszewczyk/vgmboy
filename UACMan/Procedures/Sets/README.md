# Set-Based Procedures

Set profiles define collection identity and source provenance. Apply the
[Base Set Profile](BASE-SET-PROFILE.md) together with the procedure for each
member's source format. Format procedures define which native fields are
recognized and how selected facts map to UAC.

## Profiles

- [`BASE-SET-PROFILE.md`](BASE-SET-PROFILE.md): shared source authority,
  provenance, two-pass harvesting, and unresolved-identity rules.
- [`SNESMusicOrg.md`](SNESMusicOrg.md): historic SPC soundtrack archive;
  records SNESMusic.org-specific RSN and SPC hash scopes.
- [`Project2612.md`](Project2612.md): historic Sega VGM collection; records
  its source package layout and platform/format coverage.
