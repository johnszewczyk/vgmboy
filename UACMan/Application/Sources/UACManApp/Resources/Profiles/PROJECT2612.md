# Project 2612 Set Profile

Apply the [Base Set Profile](BASE-SET-PROFILE.md) and the source-format
profile for each member. Record only Project 2612 collection facts here.

## Scope

- **Collection** — Historic Sega VGM collection covering multiple platforms
  and source formats.
- **Member formats** — Use each member's applicable source-format procedure;
  do not list unrecognized source fields in this set profile.

## Source Authority

- **Source packages** — The current Project 2612 tree contains per-game
  `.tar.zst` packages. These are source archives, not UAC output packages.
- **Collection-specific authority** — Keep source locations and collection
  references with the source records; do not infer set membership from title
  or content overlap.

## Identity Enrichment

- **Release identity** — Apply the Base Set Profile's positive, unique match
  rule. Keep platform-specific identity limits in the relevant dated review
  report.

## Set Procedures

- **Format coverage** — Apply the matching source-format profile to each
  member; keep reader-to-UAC mapping rules in those format profiles.

## Required Checks

- **Source inventory** — Verify each source archive and member relationship
  before conversion.
- **Conversion report** — Record collection counts, platform coverage, and
  unresolved identity mappings in a dated report under `Reports/`.
