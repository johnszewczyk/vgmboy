# MetaMan agent routing

Read [`project-info.md`](project-info.md), then use the owning source and the
canonical [published format map](../../VGMManDocs/Docs/md/MetaMan/format-layouts.md)
for the format being changed. Do not copy format inventories into this routing
file.

Keep reader behavior complete and decoder-independent. Preserve native source
facts, ordered and repeated metadata, unknown keys, source bytes, and diagnostics
where the format supports them. Changes that affect ScanSong catalog projection
must include the adapter and its compatibility evidence.
