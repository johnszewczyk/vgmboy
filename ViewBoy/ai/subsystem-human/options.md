# Options

Options keeps the two-pane dialog: an alphabetized, framed table of contents at the left and a larger framed page pane at the right. Filled LCD section bars labeled **OPTIONS - VIEWBOY** and **OPTIONS - VGMBoy** replace the old generic header and identify which frontend owns each page. The selected page highlight slides between sidebar buttons using the shared selection animation timing, easing, and frame-rate setting. Navigation buttons stay inside the TOC frame. Catalog reloads and incoming library snapshots update their data without dismissing Options; Back returns to the active playlist after a host snapshot. The two panes and their parent row shrink within the LCD bounds when the window resizes; the page pane keeps a minimum-width-zero clipped viewport. Its page content scrolls within that viewport so long pages do not expand the dialog or push the footer off screen. Boolean settings use plain list rows with a centered, glyph-height square: a one-dot outline when off and a filled interior when on. This applies to column visibility, cache, audio, layout, motion, and playlist favorites. Toggling a square flips it around its vertical axis using the shared animation timing. `[-]` and `[+]` stay together before numeric values or gauges. Segmented choices use equal-width buttons in a right-aligned wrapper that occupies two-thirds of the row. Opening Options slides the current screen down as the Options screen rolls in from the top; Back runs the same transition in reverse. All screen transitions use the shared animation duration and frame-rate setting. A quiet app footer shows the active file's library path on the left and elapsed time, the adjusted song length, and playlist total on the right.

Interface > Layout Spacing exposes three independent values in LCD dots. **UI Button Pad** sets text insets and standard control height. **UI Chrome Gap** sets spacing between interface controls, pane content, tab chrome, playlist headings and rows, and playlist columns. **Text Line Gap** sets the blank dots between both sidebar and playlist text rows. Each value ranges from one to eight dots; defaults are four, four, and one respectively. Changes use the shared animation duration. Legacy display settings are migrated into the unified controls when read and only the new names are saved.

## ViewBoy

- **Database** is a ViewBoy page. It shows the active catalog path, schema and indexed track count, and reloads the catalog projection. Its Archive Cache section shows the cache folder and current usage, toggles decompressed-file caching, adjusts its 2/4/8/16 GB limit, clears cached files, and reveals either path in Finder.
- **Display** selects Micro 3×5 or Standard 5×7 bitmap text and LCD dot size (2–6 device pixels per logical dot; default 3). Changing dot size resamples the same screen framebuffer with a one-device-pixel unlit seam around each shaded dot.
- **Interface** is a ViewBoy page. It controls Words or Symbols for the Previous, Play/Pause, Next, and Stop buttons, automatic column sizing, Main Window on Top, the three spacing values, and Motion. Motion puts the animation enable checkbox and duration ticker on one row, with an FPS ticker below. The shared FPS range runs from 30 to 240 in 30 FPS increments; its cap applies to selection, disclosure, resize, reorder, equalizer, spacing, scrolling, and Options screen transitions. The default is 60 FPS. The FPS value limits Canvas updates; actual presentation also depends on the display refresh rate and WKWebView compositing. Auto-sized metadata columns fit the longest value in the active table plus the heading and sort marker; the flexible Title column stays left-aligned. Headers and rows share measured widths and animate together.
- **Library** is a ViewBoy page. It persists visibility for File, Game, Artist, Path, Size, and Date/Time as a plain checkbox list. **Auto-Hide Empty Columns** hides enabled metadata columns whose values are empty in the active playlist; disabling it restores those columns. Right-click any playlist heading to open the same checkbox list in an LCD pop-up. Every enabled column remains in the table even when the screen is too narrow; the table clips to its pane and scrolls horizontally. Drag a header to reorder columns. The numbered `#` column stays first and cannot be moved. Library also reloads a fresh read from the catalog.
- **Queue** is ViewBoy's frontend-owned Repeat Off/All/One and Random Off/Playlist/Library page. These affect queue selection and are separate from VGMBoy's decoder timing and audio controls.
- **Theme** is a ViewBoy page that selects the GameBoy or NightBoy four-tone palette and standard or high-contrast ink. The palette sample shows the four screen tones.

## VGMBoy

- **Audio** provides Mono Output, Volume, and ten full-width horizontal equalizer bars from 31 Hz to 16 kHz. Volume uses the same outlined, shaded, ticked bar style and has a boxed percentage readout. Each equalizer band spans flat 0 to +12 dB in 0.5 dB steps (25 settings) and has a minimum width of 100 LCD dots before it expands to fill the pane. All ten bands share identical label, slider, value widths, horizontal insets, and row spacing. The four-shade fill begins empty at flat 0 dB and fills to the right endpoint at +12 dB, with evenly spaced tick fins. Clicking either the filled or unfilled part animates the gain and readout smoothly toward the selected snap point. The animation uses the app-wide duration and FPS cap. UI Chrome Gap sets the separation between controls and gauges. Gain, volume, and mono changes update VGMBoy playback.
- **Diagnostics** reads the shared playback status: output state, buffered and ring-buffer frames, underruns, sample rates, decoder family, tempo, and frame counters.
- **Methods** provides separate libgme and libvgm speed controls. Each enables native tempo support and adjusts rates in 1/32 steps from 1/32× to 8×. The framed rate input accepts fractions such as `15/16` and decimal values, snaps them to the shared 1/32 step, and displays a reduced fraction. The active track's backend is resolved from the native playback capability manifest; supported speed changes reconfigure the live track.
- **Playback** provides Long Play, End Fade, and track timing. Long Play's checkbox, `[-]` / `[+]` controls, and time field share one row. Its duration adjusts in 30-second steps from zero (open ended) to one hour; the unknown-length default adjusts from 30 seconds to one hour; fade duration adjusts from zero to 60 seconds. Click a timing value to edit it directly as seconds or `MM:SS`; Long Play also accepts `OPEN`. Enter or Tab commits, and Escape cancels. The paired decrease/increase controls stay before each readout.

The Search Library field clears and focuses at the start when clicked; typed text filters game and system names, Backspace edits, and Escape clears or exits search focus. The compact OPT sidebar button and Command-comma open or close Options. Command-1 through Command-9 select playlist tabs. Path View, Console View, and Disk Path remain available from the View menu and sidebar controls. Command-Shift-D opens Favorites and Command-Shift-H opens Playback History; both appear as ordinary closable and reorderable playlist tabs. F7/F8/F9 invoke Previous/Play-Pause/Next. Command-O opens a local path, Command-T duplicates the playlist in a tab, Command-W closes the current playlist tab, and Command-Q quits. Playback, interface, queue, and column-visibility preferences use the typed native preference bridge. Theme, ink, font, dot size, spacing, transport label style, and playlist column order use WebKit local storage when available. Playlist tabs and their track snapshots use a separate native `playlistTabsLoad` / `playlistTabsSave` bridge pair.

Options rolls in from the top and leaves upward; Command-comma toggles the screen in either direction. Every animation uses the same easing, duration, enablement, and configurable FPS cap. The Canvas frame gate follows requestAnimationFrame timestamps and skips updates above the selected cap. Sidebar rotates the typographic `>` in place by rasterizing its dots into the same Canvas framebuffer as the rest of the screen. Changing display settings does not stop playback.
