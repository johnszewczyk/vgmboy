# Options

Options is a single scrolling page beside its category sidebar. Shaded, left-aligned headers divide the page into sections. Sections have no surrounding dialog outlines, nested insets or columns. Display presents LCD Palette, Screen Profile, Interface, Layout Spacing and Motion in that order at every window width.

Labels occupy the left half. Compact selectors and color fields use the right half with a common trailing edge. Numeric groups stay right-aligned in that half, with square minus/plus buttons and a fixed-width readout. Checkbox controls sit on the right of their labels. Long rows use their own full-width line when they cannot fit. Contrast, Volume and FPS gauges always occupy separate full-width lines.

UI Gap separates neighboring rows; section gaps and space below headers use 2× UI Gap. Button Pad controls glyph insets and control heights. Line Gap controls the category links. Reset Spacing restores 4/4/1 dots. The transport, category sidebar, page header and footer remain visible; content scrolls internally. The gear, Escape or Command-comma returns to the library. The shared SB2 timing curve and FPS cap drive transitions.

Rendering (LCD/Direct), palette (Color/8 Gray/16 Gray), aperture, matrix, colors and Contrast Boost remain independent. PREVIEW is one continuous tone strip; 8/16-gray previews show every tone. Direct keeps the two custom endpoints and intermediate UI tones; LCD uses linear-light reflectance mixing. Invalid color drafts stay editable without changing the active palette.

## ViewBoy

- **Database** is a ViewBoy page. It shows the active catalog path, schema and indexed track count, and reloads the catalog projection. Its Archive Cache section shows the cache folder and current usage, toggles decompressed-file caching, adjusts its 2/4/8/16 GB limit, clears cached files, and reveals either path in Finder.
- **Display** is the single ViewBoy appearance and interface page. Its sections run vertically under shaded headers, with labels left, compact controls right, and gauges on full-width lines. New installations use BG `#9BBC0F`, black PIXEL `#000000`, four-tone LCD output and an enabled STN aperture. Contrast Boost adjusts ink and matrix edge density from zero through 100 percent, including binary 1 PX gutters at saturated black or white endpoints. Zero boost leaves the chosen aperture unchanged; maximum classic boost tints gutters toward ink by 65 percent, keeping them distinct. Its full-width gauge follows the numeric row and supports drag preview, commit on release and cancellation; arrows change one percent, Shift-arrow ten, Home/End select endpoints, and minus/plus changes five percent. Aperture selects the fractional STN component mask or classic 1 PX gutters. In grayscale modes TEXT SHADE sets ink and BG SHADE selects substrate; muted ink and selection tones follow the selected polarity. RENDERING selects LCD linear-light reflectance mixing or DIRECT interpolation in sRGB channels. Both preserve exact color endpoints at zero boost and retain intermediate muted/header tones. PALETTE independently selects COLOR, 8 GRAY or 16 GRAY; grayscale palettes retain their TEXT SHADE and BG SHADE controls. Matrix geometry and Contrast Boost remain independent. All methods preserve pixel grid and matrix-gap geometry. The BG and PIXEL fields accept short/long hex, RGB channel triplets, CSS names, and CSS color functions; Enter applies and Escape cancels. Hints appear only during editing, and invalid drafts stay editable with the previous palette preserved. Fields preserve entered text and save resolved RGB separately. The page also selects Micro 3×5 or Standard 5×7 bitmap text and LCD dot size (2–6 device pixels per logical dot; default 3). [Nintendo's technical data](https://www.nintendo.com/en-gb/Support/Legacy-system/Technical-data-619585.html) lists the classic LCD with 160×144 resolution and a contrast controller; the Game Boy Color uses TFT. ViewBoy does not model measured LCD voltage response. Motion puts animation enablement and duration on one row. FPS has a shared minus/plus/readout row and a full-width draggable gauge below. FPS minus/plus changes ten; the cap accepts any integer from 30 to 240 FPS and defaults to 60; arrow keys adjust one FPS, Shift-arrow adjusts ten, and Home/End select the limits. The cap applies to selection, disclosure, resize, reorder, equalizer, spacing, scrolling, and Options screen transitions. The FPS value limits Canvas updates; actual presentation also depends on the display refresh rate and WKWebView compositing.
- **Library** is a ViewBoy page. It persists visibility for File, Game, Artist, Path, and Date/Time as a plain checkbox list. **Auto-Hide Empty Columns** hides enabled metadata columns whose values are empty in the active playlist; disabling it restores those columns. Right-click any playlist heading to open the same checkbox list in an LCD pop-up. Every enabled column remains in the table even when the screen is too narrow; the table clips to its pane and scrolls horizontally. Drag a header to reorder columns. The numbered `#` column stays first and cannot be moved.
- **Queue** is ViewBoy's frontend-owned Repeat Off/All/One and Random Off/Playlist/Library page. These affect queue selection and are separate from VGMBoy's decoder timing and audio controls.

## VGMBoy

- **Audio** provides Mono Output, Volume, and ten aligned EQ bands from 31 Hz to 16 kHz. Volume uses the common numeric row above a full-width filled, ticked gauge. Each band spans flat 0 to +12 dB in 0.5 dB steps (25 settings). Every band puts its gauge on a full-width line below its label and numeric controls. All ten bands share the same control alignment. Zero has no fill and +12 dB fills the final track pixel. Ticks use normalized positions across the complete track. Step-button gain changes animate with the shared curve, duration and FPS cap; pointer gestures preview directly and apply on release, or restore the starting value on cancellation. Focused gauges accept arrows and Home/End. Options uses the configured UI Gap. Committed gain, volume and mono changes update the native VGMBoy audio configuration.
- **Diagnostics** reads the shared playback status: output state, buffered and ring-buffer frames, underruns, sample rates, decoder family, tempo, and frame counters.
- **Methods** provides separate libgme and libvgm speed controls. Each enables native tempo support and adjusts rates in 1/32 steps from 1/32× to 8×. The framed rate input accepts fractions such as `15/16` and decimal values, snaps them to the shared 1/32 step, and displays a reduced fraction. The active track's backend is resolved from the native playback capability manifest; supported speed changes reconfigure the live track.
- **Playback** provides Long Play, End Fade, and track timing. Long Play's checkbox, `[-]` / `[+]` controls, and time field share one row. Its duration adjusts in 30-second steps from zero (open ended) to one hour; the unknown-length default adjusts from 30 seconds to one hour; fade duration adjusts from zero to 60 seconds. Click a timing value to edit it directly as seconds or `MM:SS`; Long Play also accepts `OPEN`. Enter or Tab commits, and Escape cancels. The paired decrease/increase controls stay before each readout.

The Search Library field clears and focuses at the start when clicked; typed text filters game and system names, Backspace edits, and Escape clears or exits search focus. The gear Options sidebar icon and Command-comma open or close Options; the Library icon is a stack of lines. Command-1 through Command-9 select playlist tabs. Path View, Console View, Playback Queue, and Disk Path remain available from the View menu; Library and Path modes are also available from the sidebar. Command-Shift-F opens Favorites without selecting playlist rows, and Command-Shift-H opens Recent; both appear as ordinary closable and reorderable playlist tabs. F7/F8/F9 invoke Previous/Play-Pause/Next. Command-O opens a local path, Command-T duplicates the playlist in a tab, Command-W closes the current playlist tab, and Command-Q quits. Playback, interface, queue, and column-visibility preferences use the typed native preference bridge. Custom BG/PIXEL endpoints, font, dot size, spacing, transport label style, and playlist column order use WebKit local storage when available. Playlist tabs and their track snapshots use a separate native `playlistTabsLoad` / `playlistTabsSave` bridge pair.

Options rolls in from the top and leaves upward; Command-comma toggles the screen in either direction. Every animation uses cubic-bezier(0.2, 0, 0, 1), the same duration, enablement, and configurable FPS cap. The movement travels quickly and settles without overshoot. The Canvas frame gate follows requestAnimationFrame timestamps and skips updates above the selected cap. Sidebar rotates the typographic `>` in place by rasterizing its dots into the same Canvas framebuffer as the rest of the screen. Changing display settings does not stop playback.

Opening Options while startup is still loading dismisses the startup overlay for that launch. Catalog and playlist restoration continue in the background, and their completion must leave the selected Options page open.
