# Options

Options fills the LCD with a vertical table of contents and one spacious content pane. Opening Options slides the current screen down as the Options screen rolls in from the top; Back runs the same transition in reverse. The transition uses the shared resize duration, easing, and 60-frame-per-second cap. The TOC stays alphabetized: Audio, Database, Display, Interface, Library, Methods, Playback, Theme, and Transport. Each pane pins two equal-width outlined status readouts to the bottom edge. Groups use section headers and outlined rows; checkboxes show `[x]` when enabled and `[ ]` when off. `[-]` and `[+]` adjust numeric values, placed together before their value field or gauge.

The Interface page exposes three independent spacing values in LCD dots: Control Padding changes text insets and vertical padding on controls, playlist rows, and system-tree rows; UI Gap sets shared item gaps, group insets, and pane padding, including the sidebar toolbar-to-tree gap, system headings-to-games gap, and playlist headings-to-rows gap; Playlist Gap sets horizontal spacing between playlist table columns, shared by headings and track cells. Each value ranges from one to eight dots and defaults to four. Spacing and padding changes animate with the shared resize duration and easing. The LCD content stays eight dots inside the app border, and the surrounding shell has an eight-CSS-pixel outer gap.

- **Audio** provides Mono Output, Volume, and ten full-width horizontal equalizer bars from 31 Hz to 16 kHz. Each band spans flat 0 to +12 dB in 0.5 dB steps (25 settings) and has a minimum width of 100 LCD dots before it expands to fill the pane. All ten bands share identical label, slider, value widths, horizontal insets, and row spacing. The four-shade fill acts as a level gauge from flat to +12 dB, with evenly spaced tick fins; the numeric gain readout eases alongside the fill from the current value to the target using the app-wide selection animation setting, curve, and 60-frame-per-second limit. Increasing UI Gap gives the label and value columns their larger separation while allowing the fill bar to use less width. Gain, volume, and mono changes update the native audio path.
- **Database** shows the active catalog path, schema and indexed track count, and reloads the catalog projection. Its Archive Cache section shows the cache folder and current usage, toggles decompressed-file caching, adjusts its 2/4/8/16 GB limit, clears cached files, and reveals either path in Finder.
- **Display** selects Micro 3×5 or Standard 5×7 bitmap text.
- **Interface** controls automatic column sizing, header-and-row resize motion and duration, track-selection slide timing, and Main Window on Top. Auto-sized metadata columns fit the longest value in the active table plus the heading and sort marker; the flexible Title column stays left-aligned. Headers and rows share measured widths and animate together.
- **Library** persists visibility for File, Game, Artist, Path, and Size. Right-click any playlist heading to open the same checkbox list in an LCD pop-up. Every enabled column remains in the table even when the screen is too narrow; the table clips to its pane and scrolls horizontally. Drag a header to reorder columns. The numbered `#` column stays first and cannot be moved. Library also reloads a fresh read from the catalog.
- **Methods** provides separate libgme and libvgm speed controls. Each enables native tempo support and adjusts rates in 1/32 steps from 1/32× to 8×. The active track's backend is resolved from the native playback capability manifest; supported speed changes reconfigure the live track.
- **Playback** provides Long Play, End Fade, Repeat Off/All/One, Random Off/Playlist/Library, and track timing. Long Play duration adjusts in 30-second steps from zero (open ended) to one hour; the unknown-length default adjusts from 30 seconds to one hour; fade duration adjusts from zero to 60 seconds. Click a timing value to edit it directly as seconds or `MM:SS`; Long Play also accepts `OPEN`. Enter or Tab commits, and Escape cancels. The paired decrease/increase controls stay before each readout.
- **Theme** selects the GameBoy or NightBoy four-tone palette and standard or high-contrast ink. The palette sample shows the four screen tones.
- **Transport** selects Words or Symbols for the Previous, Play/Pause, Next, and Stop buttons. The symbol set uses authored bitmap glyphs.

The sidebar's Search Library field filters game and system names as bitmap text is typed; Backspace edits, Escape clears, and a second Escape exits search focus. The compact OPT sidebar button and Command-comma open Options. The shared shortcuts are Command-1 Path View, Command-2 Console View, Command-3 Disk Path, Command-Shift-D Favorites, Command-Shift-H Playback History, and F7/F8/F9 Previous/Play-Pause/Next. Command-O opens a local path, Command-T duplicates the playlist in a tab, Command-W closes the current playlist tab, and Command-Option-1 through Command-Option-9 select tabs. Command-Q quits. Playback, interface, and column-visibility preferences use the typed native preference bridge. Theme, ink, font, spacing, transport label style, and playlist column order use WebKit local storage when available. Playlist tabs and their track snapshots use a separate native `playlistTabsLoad` / `playlistTabsSave` bridge pair.

Options rolls in from the top and leaves upward; Command-comma toggles the screen in either direction. Selection, sidebar disclosure, column-width, spacing, and equalizer-gain animations use the shared easing curve and update at no more than 60 frames per second. Sidebar uses a typographic `>` inside a uniform pixel square and rotates it in place with Metal in the native host (the browser preview rasterizes the same glyph). Animation duration and enablement remain user-adjustable in Interface. Changing display settings does not stop playback.
