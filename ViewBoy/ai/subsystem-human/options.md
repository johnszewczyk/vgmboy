# Options

Options is an in-place view of the app shell. The single-line transport toolbar, compact sidebar, and quiet playback footer remain in place while the playlist area becomes the selected Options page. The sidebar keeps its action row beneath an Options heading and replaces library rows with grouped ViewBoy and VGMBoy page links; the selected page uses a shaded marker that glides with the shared SB2 timing curve. The navigation/content panes use matching filled headers and share the configured UI Gap inset. The content pane scrolls internally when a page is taller than the available area. Selecting a page or changing a control leaves Options open. The gear, Escape, and Command-comma return to the library using the existing roll transition. Database reloads and delayed catalog, Favorites, or Recent updates preserve the current page. The Display page uses two columns in wide panes and stacked cards in narrow panes: LCD palette and screen profile on the left, a combined Interface card, layout spacing and motion on the right. Display sections use full cards with a shared filled title bar and outline. Options shares the saved Layout Spacing values with the main screen: UI Gap changes pane/card insets and row gaps, Button Pad changes control heights and text insets, and Line Gap changes page-link spacing. Reset Spacing restores defaults of 4/4/1 dots. Boolean settings use plain list rows with a centered, glyph-height square; a one-dot outline marks off and a filled interior marks on. `-` and `+` stay adjacent before numeric values or gauges; Contrast Boost, Volume and FPS each use one label/minus/plus/readout row and a separate full-width ticked gauge below. Numeric readouts reserve the same width and steppers are square. Two-way segmented choices use matching, bounded, right-aligned wrappers; Aperture precedes Font in the same group. Selector widths are bounded by count, with matching Random/Repeat geometry. Narrow panes place labels above the buttons. The pixel-method row reserves each label's minimum width. BG/PIXEL fields share a bounded width. The Options sidebar fits its six icons with the configured UI Gap insets, and page links include vertical room for their selection border. The shared footer shows the active file path and playback clock. All screen transitions use the shared animation duration, easing, and frame-rate setting.

Display > Layout Spacing exposes UI Button Pad, UI Chrome Gap, and Text Line Gap for the main screen and Options. The fixed eight-LCD-pixel app-edge inset is separate from these controls. UI Button Pad sets control text insets and standard control height; UI Chrome Gap separates controls, panes, cards, headings and playlist columns; Text Line Gap sets blank space between library/playlist rows and Options page links. Each adjustable value ranges from one to eight dots, with defaults of four, four, and one. Changes are visible immediately in Options. Borders remain outside the glyphs at the minimum one-dot padding. Changes use the shared animation duration. Legacy display spacing settings are migrated on read, and only the unified setting names are saved.

## ViewBoy

- **Database** is a ViewBoy page. It shows the active catalog path, schema and indexed track count, and reloads the catalog projection. Its Archive Cache section shows the cache folder and current usage, toggles decompressed-file caching, adjusts its 2/4/8/16 GB limit, clears cached files, and reveals either path in Finder.
- **Display** is the single ViewBoy appearance and interface page. Its responsive card layout places the shade preview, editable BG/PIXEL fields, and screen profile on the left; transport labels, playlist auto-sizing, layout spacing, window behavior, and Motion are on the right. Each section is a full card with a shared filled title bar and enclosing outline. New installations use BG `#9BBC0F`, black PIXEL `#000000`, four-tone LCD output and an enabled STN aperture. Contrast Boost adjusts ink and matrix edge density from zero through 100 percent, including binary 1 PX gutters at saturated black or white endpoints. Zero boost leaves the chosen aperture unchanged; maximum classic boost tints gutters toward ink by 65 percent, keeping them distinct. Its full-width gauge follows the numeric row and supports drag preview, commit on release and cancellation; arrows change one percent, Shift-arrow ten, Home/End select endpoints, and minus/plus changes five percent. Aperture selects the fractional STN component mask or classic 1 PX gutters. In grayscale modes TEXT SHADE sets ink and BG SHADE selects substrate; muted ink and selection tones follow the selected polarity. At zero Contrast Boost, Direct maps framebuffer ink/background to exact CSS endpoints; 8/16 map them to grayscale ramps. All methods preserve pixel grid and matrix-gap geometry. The BG and PIXEL fields accept short/long hex, RGB channel triplets, CSS names, and CSS color functions; Enter applies and Escape cancels. Hints appear only during editing, and invalid drafts stay editable with the previous palette preserved. Fields preserve entered text and save resolved RGB separately. The page also selects Micro 3×5 or Standard 5×7 bitmap text and LCD dot size (2–6 device pixels per logical dot; default 3). [Nintendo's technical data](https://www.nintendo.com/en-gb/Support/Legacy-system/Technical-data-619585.html) lists the classic LCD with 160×144 resolution and a contrast controller; the Game Boy Color uses TFT. ViewBoy does not model measured LCD voltage response. Motion puts animation enablement and duration on one row. FPS has a shared minus/plus/readout row and a full-width draggable gauge below. FPS minus/plus changes ten; the cap accepts any integer from 30 to 240 FPS and defaults to 60; arrow keys adjust one FPS, Shift-arrow adjusts ten, and Home/End select the limits. The cap applies to selection, disclosure, resize, reorder, equalizer, spacing, scrolling, and Options screen transitions. The FPS value limits Canvas updates; actual presentation also depends on the display refresh rate and WKWebView compositing.
- **Library** is a ViewBoy page. It persists visibility for File, Game, Artist, Path, and Date/Time as a plain checkbox list. **Auto-Hide Empty Columns** hides enabled metadata columns whose values are empty in the active playlist; disabling it restores those columns. Right-click any playlist heading to open the same checkbox list in an LCD pop-up. Every enabled column remains in the table even when the screen is too narrow; the table clips to its pane and scrolls horizontally. Drag a header to reorder columns. The numbered `#` column stays first and cannot be moved.
- **Queue** is ViewBoy's frontend-owned Repeat Off/All/One and Random Off/Playlist/Library page. These affect queue selection and are separate from VGMBoy's decoder timing and audio controls.

## VGMBoy

- **Audio** provides Mono Output, Volume, and ten aligned EQ bands from 31 Hz to 16 kHz. Volume uses the common numeric row above a full-width filled, ticked gauge. Each band spans flat 0 to +12 dB in 0.5 dB steps (25 settings). Wider panes keep inline gauges; narrower panes put each gauge below its numeric controls. All ten bands share label, slider and value columns. Zero has no fill and +12 dB fills the final track pixel. Ticks use normalized positions across the complete track. Step-button gain changes animate with the shared curve, duration and FPS cap; pointer gestures preview directly and apply on release, or restore the starting value on cancellation. Focused gauges accept arrows and Home/End. Options uses the configured UI Gap. Committed gain, volume and mono changes update the native VGMBoy audio configuration.
- **Diagnostics** reads the shared playback status: output state, buffered and ring-buffer frames, underruns, sample rates, decoder family, tempo, and frame counters.
- **Methods** provides separate libgme and libvgm speed controls. Each enables native tempo support and adjusts rates in 1/32 steps from 1/32× to 8×. The framed rate input accepts fractions such as `15/16` and decimal values, snaps them to the shared 1/32 step, and displays a reduced fraction. The active track's backend is resolved from the native playback capability manifest; supported speed changes reconfigure the live track.
- **Playback** provides Long Play, End Fade, and track timing. Long Play's checkbox, `[-]` / `[+]` controls, and time field share one row. Its duration adjusts in 30-second steps from zero (open ended) to one hour; the unknown-length default adjusts from 30 seconds to one hour; fade duration adjusts from zero to 60 seconds. Click a timing value to edit it directly as seconds or `MM:SS`; Long Play also accepts `OPEN`. Enter or Tab commits, and Escape cancels. The paired decrease/increase controls stay before each readout.

The Search Library field clears and focuses at the start when clicked; typed text filters game and system names, Backspace edits, and Escape clears or exits search focus. The gear Options sidebar icon and Command-comma open or close Options; the Library icon is a stack of lines. Command-1 through Command-9 select playlist tabs. Path View, Console View, Playback Queue, and Disk Path remain available from the View menu; Library and Path modes are also available from the sidebar. Command-Shift-F opens Favorites without selecting playlist rows, and Command-Shift-H opens Recent; both appear as ordinary closable and reorderable playlist tabs. F7/F8/F9 invoke Previous/Play-Pause/Next. Command-O opens a local path, Command-T duplicates the playlist in a tab, Command-W closes the current playlist tab, and Command-Q quits. Playback, interface, queue, and column-visibility preferences use the typed native preference bridge. Custom BG/PIXEL endpoints, font, dot size, spacing, transport label style, and playlist column order use WebKit local storage when available. Playlist tabs and their track snapshots use a separate native `playlistTabsLoad` / `playlistTabsSave` bridge pair.

Options rolls in from the top and leaves upward; Command-comma toggles the screen in either direction. Every animation uses cubic-bezier(0.2, 0, 0, 1), the same duration, enablement, and configurable FPS cap. The movement travels quickly and settles without overshoot. The Canvas frame gate follows requestAnimationFrame timestamps and skips updates above the selected cap. Sidebar rotates the typographic `>` in place by rasterizing its dots into the same Canvas framebuffer as the rest of the screen. Changing display settings does not stop playback.

Opening Options while startup is still loading dismisses the startup overlay for that launch. Catalog and playlist restoration continue in the background, and their completion must leave the selected Options page open.
