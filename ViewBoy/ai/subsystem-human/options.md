# Options

Options uses one shared navigation rail and one content area on every page. The alphabetized rail is 176 logical dots wide, capped at 24% of the available width; a single LCD divider separates it from the content. Neither area has a surrounding frame. Plain owner labels sit above each group of page buttons. The selected page highlight slides between rail buttons using the shared timing, easing, and frame-rate setting; its fill stays inside the button's one-dot outline. Catalog reloads and delayed Path/Favorites/History results update their data without dismissing Options or changing its return playlist. A host library snapshot preserves the page and sets Back's return destination to the active queue. Only Back, Escape, and Command-comma dismiss Options. When the window narrows, the rail follows the same width cap and the content area clips and scrolls without pushing the footer off screen. All pages use a fixed spacing grid: 8-dot pane inset, 4-dot card inset, 4-dot gaps, and 4-dot control padding. This keeps cards and controls aligned regardless of saved main-screen spacing preferences. The Display page is a two-column workspace: its LCD palette preview and screen profile are on the left, while transport, layout, window, and motion settings are on the right. Each Display section uses a full card with a shared filled title bar and enclosing outline. Other pages retain their existing grouped settings sections. Boolean settings use plain list rows with a centered, glyph-height square: a one-dot outline when off and a filled interior when on. This applies to column visibility, cache, audio, layout, motion, and playlist favorites. Toggling a square flips it around its vertical axis using the shared timing. `[-]` and `[+]` stay together before numeric values or gauges. Segmented choices use equal-width buttons in a right-aligned wrapper that occupies two-thirds of the row. Opening Options slides the current screen down as the Options screen rolls in from the top; Back runs the same transition in reverse. All screen transitions use the shared animation duration and frame-rate setting. A quiet app footer shows the active file's library path on the left and elapsed time, the adjusted song length, and playlist total on the right.

Display > Layout Spacing exposes UI Button Pad, UI Chrome Gap, and Text Line Gap for the main screen. The fixed eight-LCD-pixel app-edge inset is separate from these controls. UI Button Pad sets main-screen control text insets and standard control height; UI Chrome Gap separates main-screen controls, panes, headings, and playlist columns; Text Line Gap sets the blank space between sidebar and playlist text rows. Each adjustable value ranges from one to eight dots, with defaults of four, four, and one. Options keeps its own fixed grid and does not change when these values change. Changes use the shared animation duration. Legacy display spacing settings are migrated on read, and only the unified setting names are saved.

## ViewBoy

- **Database** is a ViewBoy page. It shows the active catalog path, schema and indexed track count, and reloads the catalog projection. Its Archive Cache section shows the cache folder and current usage, toggles decompressed-file caching, adjusts its 2/4/8/16 GB limit, clears cached files, and reveals either path in Finder.
- **Display** is the single ViewBoy appearance and interface page. Its two-column layout places the four-tone palette preview, editable BG/PIXEL fields, and screen profile on the left; transport labels, playlist auto-sizing, layout spacing, window behavior, and Motion are on the right. Each section is a full card with a shared filled title bar and enclosing outline. The default palette is the traditional Game Boy colors: BG `#9BBC0F`, PIXEL `#222222`. The BG and PIXEL fields accept short/long hex, RGB channel triplets, CSS names, and CSS color functions; Enter applies and Escape cancels. The fields preserve entered text and save resolved RGB separately. The renderer derives two intermediate tones between those endpoints at equal CIELAB L* intervals. Pixel Matrix Gaps is off by default for full palette coverage; enabling it adds a one-device-pixel LCD-background edge to each cell. **Raw Pixels** is a persisted high-contrast mode with two exact endpoints: shades 0–2 use PIXEL and shade 3 uses BG. It changes shade mapping only; Pixel Matrix Gaps continues to draw the configured cell edges, keeping the pixel grid visible. Selected control labels reverse to BG and row selection uses a pixel outline. The page also selects Micro 3×5 or Standard 5×7 bitmap text and LCD dot size (2–6 device pixels per logical dot; default 3). [Nintendo's technical data](https://www.nintendo.com/en-gb/Support/Legacy-system/Technical-data-619585.html) lists the classic LCD with 160×144 resolution and a contrast controller; the Game Boy Color uses TFT. Equal L* spacing is ViewBoy's consistent digital palette rule, not a measured LCD voltage curve. Motion puts animation enablement and duration on one row, with one draggable FPS cap slider and numeric readout below. The cap accepts any integer from 30 to 240 FPS and defaults to 60; arrow keys adjust one FPS, Shift-arrow adjusts ten, and Home/End select the limits. The cap applies to selection, disclosure, resize, reorder, equalizer, spacing, scrolling, and Options screen transitions. The FPS value limits Canvas updates; actual presentation also depends on the display refresh rate and WKWebView compositing.
- **Library** is a ViewBoy page. It persists visibility for File, Game, Artist, Path, and Date/Time as a plain checkbox list. **Auto-Hide Empty Columns** hides enabled metadata columns whose values are empty in the active playlist; disabling it restores those columns. Right-click any playlist heading to open the same checkbox list in an LCD pop-up. Every enabled column remains in the table even when the screen is too narrow; the table clips to its pane and scrolls horizontally. Drag a header to reorder columns. The numbered `#` column stays first and cannot be moved.
- **Queue** is ViewBoy's frontend-owned Repeat Off/All/One and Random Off/Playlist/Library page. These affect queue selection and are separate from VGMBoy's decoder timing and audio controls.

## VGMBoy

- **Audio** provides Mono Output, Volume, and ten full-width horizontal equalizer bars from 31 Hz to 16 kHz. Volume uses the same outlined, shaded, ticked bar style and has a boxed percentage readout. Each equalizer band spans flat 0 to +12 dB in 0.5 dB steps (25 settings) and has a minimum width of 100 LCD dots before it expands to fill the pane. All ten bands share identical label, slider, value widths, horizontal insets, and row spacing. The four-shade fill begins empty at flat 0 dB and fills to the right endpoint at +12 dB, with evenly spaced tick fins. Clicking either the filled or unfilled part animates the gain and readout smoothly toward the selected snap point. The animation uses the app-wide duration and FPS cap. UI Chrome Gap sets the separation between controls and gauges. Gain, volume, and mono changes update VGMBoy playback.
- **Diagnostics** reads the shared playback status: output state, buffered and ring-buffer frames, underruns, sample rates, decoder family, tempo, and frame counters.
- **Methods** provides separate libgme and libvgm speed controls. Each enables native tempo support and adjusts rates in 1/32 steps from 1/32× to 8×. The framed rate input accepts fractions such as `15/16` and decimal values, snaps them to the shared 1/32 step, and displays a reduced fraction. The active track's backend is resolved from the native playback capability manifest; supported speed changes reconfigure the live track.
- **Playback** provides Long Play, End Fade, and track timing. Long Play's checkbox, `[-]` / `[+]` controls, and time field share one row. Its duration adjusts in 30-second steps from zero (open ended) to one hour; the unknown-length default adjusts from 30 seconds to one hour; fade duration adjusts from zero to 60 seconds. Click a timing value to edit it directly as seconds or `MM:SS`; Long Play also accepts `OPEN`. Enter or Tab commits, and Escape cancels. The paired decrease/increase controls stay before each readout.

The Search Library field clears and focuses at the start when clicked; typed text filters game and system names, Backspace edits, and Escape clears or exits search focus. The gear Options sidebar icon and Command-comma open or close Options; the Library icon is a stack of lines. Command-1 through Command-9 select playlist tabs. Path View, Console View, Playback Queue, and Disk Path remain available from the View menu; Library and Path modes are also available from the sidebar. Command-Shift-F opens Favorites without selecting playlist rows, and Command-Shift-H opens Playback History; both appear as ordinary closable and reorderable playlist tabs. F7/F8/F9 invoke Previous/Play-Pause/Next. Command-O opens a local path, Command-T duplicates the playlist in a tab, Command-W closes the current playlist tab, and Command-Q quits. Playback, interface, queue, and column-visibility preferences use the typed native preference bridge. Custom BG/PIXEL endpoints, font, dot size, spacing, transport label style, and playlist column order use WebKit local storage when available. Playlist tabs and their track snapshots use a separate native `playlistTabsLoad` / `playlistTabsSave` bridge pair.

Options rolls in from the top and leaves upward; Command-comma toggles the screen in either direction. Every animation uses the same easing, duration, enablement, and configurable FPS cap. The Canvas frame gate follows requestAnimationFrame timestamps and skips updates above the selected cap. Sidebar rotates the typographic `>` in place by rasterizing its dots into the same Canvas framebuffer as the rest of the screen. Changing display settings does not stop playback.
