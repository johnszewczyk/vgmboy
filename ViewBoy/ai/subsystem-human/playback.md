# Playback and Transport

Selecting a catalog game loads its indexed tracks through `databaseGameTracks`; no source rescan occurs. The sidebar Path view uses `databaseFileTree`, `databaseFolderTracks`, and `databaseFileTracks` to browse indexed catalog folders and files. Playlist selection follows standard list behavior: click selects one track, Command-click toggles a row, Shift-click selects the inclusive range from the anchor, Command-A selects all, and Escape or clicking empty table space clears selection. The primary selected track remains distinct from the playing track. Double-click or Enter starts the selected track. Right-clicking a sidebar game, system, Path folder, or file offers Play Now and Enqueue. Play Now replaces the active playlist and starts its first track; Enqueue appends unique tracks and, when that playlist owns playback, adds them to its live playback queue without interrupting the current track. Tab selection changes the displayed list and browsed playlist, while the active playback queue stays latched to the playlist from which the current track started. Previous, Next, random selection, and natural completion continue against that playback queue after browsing another tab. Starting a track from another playlist switches the playback queue to that playlist. Tab snapshots persist the primary selection, selected track IDs, range anchor, and scroll position in the native ViewBoy preferences store. Favorites and History are ordinary closable, reorderable tabs backed by their shared-store projections; opening Favorites clears track selection until the user selects rows. The transport buttons and macOS Playback menu route Previous, Play/Pause, Next, and Stop to the existing native bridge. The Transport page switches the in-app buttons between words and bitmap symbols (`<<`, `>`, `||`, `>>`, and `[]`). The main screen has one full-width toolbar row with Previous, Stop, Play/Pause, Next, and the four playback-mode shortcuts. Long Play (`LP`), Repeat One (`R1`), Playlist Random (`P-RND`), and Library Random (`L-RND`) are filled when enabled.

The Yoga canvas listens for pushed `nativePlaybackState` and `nativePlaybackEnded` events. It displays transport state and current track without polling the decoder. On natural completion, it calls `playbackCompletionRetire` to retire the finished native generation. Repeat One takes precedence and restarts the current track. Otherwise Playlist Random chooses an unplayed track from the active queue; it visits each track once before stopping, or begins another cycle when Repeat All is selected. Library Random chooses a game weighted by its indexed track count and loads only that game's tracks before choosing a song. Neither random mode hydrates the complete library playlist. Previous and Next follow the most recent 256 random tracks; changing random mode starts a new history. Playback generation guards prevent a late end event from advancing a newer track.

Options exposes Long Play, End Fade, Repeat Off/All/One, Random Off/Playlist/Library, and track timing on Playback; libgme/libvgm speed controls have a separate Methods page. Long Play Time, Unknown Length, and Fade Length have adjacent `[-]` and `[+]` controls followed by an editable time field. Click the field and enter seconds or `MM:SS`; Long Play also accepts `OPEN`. Enter or Tab commits, and Escape cancels. Speed rates advance in 1/32 steps; ViewBoy reads the native backend capability manifest and applies tempo only to supported formats. Audio controls place each `[-]`/`[+]` pair before its equalizer or volume gauge and call `nativePlaybackAudioConfig`; timing and speed controls call `nativePlaybackReconfigure` for a loaded track. Changes persist through the typed native preferences snapshot. The Favorites tab reads and updates the shared favorite store. Successful native playback starts append a record through the shared PlaybackHistory bridge; the History tab presents newest plays with a `DATE/TIME` column.

Opening a local path through the File menu uses native `choosePath`; a chosen folder is projected to its directly playable tracks through `selectFolder`. Standalone Zstandard-compressed media (`.zst` and `.zstd`) is supported as one file; TAR+Zstandard archives (`.tar.zst`, `.tar.zstd`, and `.tzst`) are not. The canvas shows the chosen selection in the Queue view. Shared shortcuts are Command-1 through Command-9 for playlist tabs, Command-Shift-F for Favorites, Command-Shift-H for History, Command-comma for Options, and F7/F8/F9 for Previous/Play-Pause/Next. Path, Console, and Disk Path remain in the View menu and sidebar. Command-W closes the active playlist tab, Command-T duplicates a playlist in a new tab, and Command-O opens a local path.
