# Playback and Transport

Selecting a catalog game loads its indexed tracks through `databaseGameTracks`; no source rescan occurs. A single click selects a track, and double-click or Enter starts it. The selected game's tracks open or reuse a named playlist tab. `[+]` duplicates the active playlist; `[x]` closes the tab, leaving one empty playlist available. Tab selection changes the displayed list and playback queue. Tab snapshots persist in the native ViewBoy preferences store. The transport buttons and macOS Playback menu route Previous, Play/Pause, Next, and Stop to the existing native bridge. The toolbar also has quick toggles for Long Play (`LP`), Repeat One (`R1`), Playlist Random (`P-RND`), and Library Random (`L-RND`); a filled button marks an enabled mode.

The Yoga canvas listens for pushed `nativePlaybackState` and `nativePlaybackEnded` events. It displays transport state and current track without polling the decoder. On natural completion, it calls `playbackCompletionRetire` to retire the finished native generation. Repeat One takes precedence and restarts the current track. Otherwise Playlist Random chooses an unplayed track from the active queue; it visits each track once before stopping, or begins another cycle when Repeat All is selected. Library Random chooses a game weighted by its indexed track count and loads only that game's tracks before choosing a song. Neither random mode hydrates the complete library playlist. Previous and Next follow the most recent 256 random tracks; changing random mode starts a new history. Playback generation guards prevent a late end event from advancing a newer track.

Options exposes Long Play, End Fade, Repeat Off/All/One, Random Off/Playlist/Library, and separate libgme/libvgm speed controls, alongside Mono, Volume, the ten-band equalizer, and the switchable LCD font and contrast. Speed rates advance in 1/32 steps; ViewBoy reads the native backend capability manifest and applies tempo only to supported formats. Changes persist through the typed native preferences snapshot. Audio controls call `nativePlaybackAudioConfig`; timing and speed controls call `nativePlaybackReconfigure` for a loaded track. The Favorites view reads and updates the shared favorite store.

Opening a local path through the File menu uses native `choosePath`; a chosen folder is projected to its directly playable tracks through `selectFolder`. The canvas shows that selection in the Queue view.
