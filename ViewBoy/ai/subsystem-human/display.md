# Display

ViewBoy uses one responsive LCD canvas for the library, playlist, options, and playback status. Yoga lays out the screen; a four-shade framebuffer paints every border, selection, control, and bitmap glyph. Three flat grey Game Boy membrane lines frame the LCD.

The main screen has two centered toolbar rows inside a half-width wrapper. Previous, Play/Pause, Next, and Stop fill equal shares of the first row; Long Play, Repeat One, Playlist Random, and Library Random fill the second. Options is in the sidebar action row, and both playback rows disappear while Options is open. The sidebar has no section banners: its pixel-rendered search field and Library, Queue, Favorites, Open, Sync, and Options controls lead directly into the catalog system tree. Clicking Search Library focuses and highlights the field, shows a blinking bitmap `|` cursor, and typing filters game and system names; Escape clears the query, and a second Escape leaves search. Expanding a system reveals its games within the fixed sidebar frame; the tree viewport clips and scrolls its rows without resizing the sidebar or shifting the playlist pane. Wheel scrolling follows fractional LCD-dot deltas, so it can stop between rows. Selecting a system folds or unfolds its games, and selecting a game loads tracks from the read-only catalog bridge. System disclosure follows the shared auto-resize motion setting. The sidebar footer reports matching catalog counts while searching, the selected system's game count, or the selected game's track count. Current Queue shows the active playback list, or the browsed game's tracks before playback starts. Favorites comes from the shared favorite store.

The track pane begins with playlist tabs, followed by centered column headings. It has no separate catalog or queue title row. Selecting a game in the sidebar opens or reuses a named tab containing that game's tracks. Selecting a tab makes its list the visible playlist; while a track is playing, browsing another tab does not replace the latched playback queue. Each tab is one outlined rectangle with its left-aligned title on the left and an unframed `X` on the right; titles shrink and end in an ellipsis glyph when space is limited. Tabs use the shared auto-resize easing to slide open when added and slide shut when closed. Drag a tab to reorder it; neighboring tabs push aside with the same easing, and the final order persists in the native playlist snapshot. `[+]` duplicates the selected playlist in a new tab. One empty playlist remains available, and up to 64 playlist snapshots persist through ViewBoy's native preference store. The Favorites view uses the shared favorite projection and hides playlist tabs.

The table can show the numbered `#`, favorite, file, title, game, artist, system, path, length, and size columns. The first `#` column is fixed, numbered to fit the list, and numbers each displayed row. The favorite column is labeled `FAV` and shows `[x]` or `[]`; clicking its cell updates the shared favorite store. Right-click any table header to show or hide File, Game, Artist, Path, and Size. Options exposes the same visibility controls. Every enabled column remains present in a horizontally scrollable viewport; trackpad horizontal scroll, Shift+wheel, Shift+Left/Right, and the bottom scrollbar move it. Drag header cells to reorder columns; neighboring headings push aside with the shared resize easing, and `#` remains pinned. Column order is remembered in local display preferences. When Auto-size Columns is enabled, metadata widths fit their headings and available values within their column caps. Header and row widths ease together when the set changes.

Buttons, outlined choices, option rows, pane headings, tab frames, and playlist headers share a font-derived row height and the same text inset. The Interface page adjusts Control Padding, UI Gap, and Playlist Gap independently, in one-dot increments. Control Padding sets text insets and vertical breathing room on controls, playlist rows, and system-tree rows. UI Gap sets shared interface spacing, including the gaps between tabs and between the tab strip and playlist headings; it also scales group and pane insets. Playlist Gap sets the horizontal spacing shared by playlist column headings and track cells. Sidebar navigation buttons share their available width, and its search field follows the same control height, border, padding, and gap. Sidebar, playlist, and Options footers use a full-outline status button pinned to the bottom of each pane.

The Options screen uses a vertical table of contents and one large content pane. It contains Display, Theme, Transport, Playback, Methods, Audio, Interface, and Library pages. Audio presents ten horizontal equalizer bars, each at least 100 LCD dots wide and otherwise filling the pane. Every band uses the same label width, slider width and height, value width, horizontal inset, and vertical spacing. Each bar selects one of 25 gain values from flat 0 to +12 dB in 0.5 dB increments and sends changes through the native audio preference path. The fill, marker, and numeric gain readout animate together with the app easing duration and curve, and refresh at no more than 60 frames per second.

The Micro 3×5 and Standard 5×7 bitmap fonts are independently authored and switchable on the Display page. The Theme page selects GameBoy or NightBoy palettes and standard or high-contrast ink. Both palettes map the same four framebuffer shades; High Contrast changes tone 0 (`#333333` for GameBoy and brighter silver for NightBoy) without adding a fifth display value. NightBoy also changes the narrow membrane lines to a dark-purple surround with silver details.

Each logical dot occupies a 3×3 device-pixel cell with a 2×2 shaded face and an unlit LCD seam. The grid scales with available space and device-pixel ratio, independent of the Game Boy's native 160×144 resolution. Selection, disclosure, and column-width animation frames are capped at an average of 60 updates per second. The frame gate advances on nominal 60 Hz intervals rather than resetting to each display refresh callback, preserving the cadence on 90 Hz and 144 Hz displays as well as 60 Hz displays. Timestamp simulations cover 60, 90, 120, and 144 Hz; actual presentation timing in WKWebView still depends on macOS compositing.

The renderer models the visible dot matrix and four quantized LCD tones, not the Game Boy's controller or electrical drive circuitry. Circuit-level simulation would not improve this app's screen output. Future authenticity work should focus on measurable optical traits such as dot aperture, cell edge, subtle viewing-angle shading, and restrained pixel response or ghosting. Keep any response effect frame-delta based and optional so static text remains crisp and canvas redraws stay inexpensive.

Click the sidebar toolbar to change views, open a path, or reload the catalog; click a tree row to open or close a system group or select a game. Click a track to select it, double-click to play it, and click a header to sort. Right-click a header to open the LCD column visibility menu. Command-1 through Command-9 select playlist tabs; Command-comma opens Options; Command-W closes the main window, and Command-Q quits ViewBoy. Arrow keys move selection, Enter plays, Space toggles playback, and unmodified 1–3 open Library, Queue, and Options. The macOS menus and playback commands use the same native bridge.
