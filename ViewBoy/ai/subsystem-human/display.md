# Display

Options uses 1× UI Gap for card/pane insets and neighboring controls, and 2× UI Gap between cards/columns and below pane or card headers. The PREVIEW row contains one bounded, continuous tone strip aligned with the BG/PIXEL fields. METHOD labels four equal-width LCD/Direct/8/16 buttons. The preview shows all eight or sixteen tones in grayscale modes, with ink/background markers inside the strip.

ViewBoy uses one responsive LCD canvas for library, playlist, options, and playback. Yoga lays out the semantic framebuffer; the display model expands its ink, muted ink, selection and substrate labels into device cells. New installations use four-tone LCD output, an enabled STN aperture, yellow-green BG and black PIXEL. Direct, 8-step and 16-step output remain available. Contrast Boost strengthens ink and matrix edge density, including binary 1 PX gutters with saturated black or white pixels, without changing the matrix setting, dot pitch, layout or spacing. Grayscale TEXT SHADE and BG SHADE remain independently adjustable. Both dark-on-light and inverse tones are supported. The root content retains its fixed eight-dot inset and the LCD surface fills the window.

Options has matching filled navigation/content headers. Layout Spacing changes Options and the main screen immediately; Reset Spacing restores pad/gap/line values to 4/4/1.

The Display page groups colors, screen profile, interface behavior, spacing, and motion into five cards. Contrast uses the common label/minus/plus/readout row above a full-width filled, ticked gauge. FPS follows the same format. The slider supports dragging and fine keyboard steps; contrast minus/plus uses five-percent steps. Aperture and Font are adjacent, alphabetically ordered segmented selectors with matching columns. Zero boost reproduces the chosen aperture without a readability override. Color editing hints are contextual, and invalid drafts remain editable.

The published color and spacing specification is [ViewBoy UI Design](../../../VGMManDocs/Docs/md/ViewBoy/ui-design.md).

If startup lasts beyond a short reveal delay, the LCD shows a centered startup card with a pixel-letter mark, a four-step stage list, progress bar, and elapsed-time readout. It briefly confirms readiness and remains visible with the startup error if loading fails.

Opening Options while startup is in progress dismisses that overlay for the current launch. The catalog and sidebar keep loading in the background, and completion must preserve the selected Options page.

The shared shell has one full-width toolbar row containing Previous, Stop, Play/Pause, Next, Long Play, Repeat One, Playlist Random, and Library Random, in that order. All eight controls use one shared button template: equal row share, height, border, and default inset. Symbol transport labels are `<<`, `[]`, `>`, and `>>` in that order; the left chevrons sit just inside the leading border. The toolbar remains visible while Options is open.

The main library sidebar has no section banners; Options uses a filled navigation header matching its content header. Beneath its pixel-rendered search field is one row of six equal square icon buttons for Library, Path, Favorites, Recent, Fold/Unfold Tree, and Options. Their nine-dot artwork uses the same size and button geometry regardless of the selected text font. Library uses a stack of lines, Favorites uses a heart, Recent uses a clock, Fold/Unfold Tree uses a branch diagram, and Options uses a gear. Queue, Reload, and local path opening are outside this toolbar: **View > Playback Queue** opens the active queue, **Options > Database** reloads the catalog and shows progress, and **File > Open Path…** or Command-O selects a local path. Switching between Library and Path changes only the sidebar tree mode and preserves the playlist cursor and scroll position.

The unfocused `SEARCH LIBRARY` placeholder uses the muted ink tone; active query text uses the darkest tone. Clicking the field clears and focuses it at the start, showing a blinking bitmap `|` cursor; typing filters catalog game/system names or catalog paths, and Escape clears the query or leaves search. Library groups games by system. Path lists indexed root folders and their folders/files; click a folder to expand or collapse it, double-click to load its tracks, and click a file to load its indexed tracks. Root chevron ink aligns with the leading edge of the search and toolbar controls; nested disclosures and labels indent by one glyph advance per depth. Depth consumes only the leading inset; the trailing inset stays at the configured control pad. Hover exposes the full source name. The main sidebar adapts to the window width and can be resized using its dotted edge; double-click resets adaptive width. Folder and file labels align at the same depth column. The Path selection is remembered in local display preferences. The tree viewport clips and scrolls rows without resizing the sidebar or shifting the playlist pane. Wheel scrolling follows fractional LCD-dot deltas, so it can stop between rows. Bitmap `>` disclosure glyphs align with their row text and rotate in place as rows fold or unfold, using the shared animation timing. Child rows keep their full glyph height and slide through a clipped opening beneath their parent instead of compressing as the group folds or unfolds. Sidebar text rows are glyph-height; **Text Line Gap** alone sets the blank space between sidebar and playlist rows, independent of UI Chrome Gap. The selected sidebar row's single shaded band slides with the playlist cursor using the shared animation duration, easing, and FPS cap; it extends one LCD dot above and below the text line. Selecting a game or path loads tracks from the read-only catalog bridge. Favorites and Recent load their shared-store projections into ordinary playlist tabs with the same selection, close, reorder, and persistence behavior as other tabs. No pane has its own footer. The quiet app footer shows the active file path on the left and elapsed time, adjusted song duration, and playlist total on the right; Long Play and fade are included when the active backend supports Long Play.

The track pane begins with playlist tabs, followed by centered column headings. It has no separate catalog or queue title row. Selecting a game in the sidebar opens or reuses a named tab containing that game's tracks. Selecting a tab makes its list the visible playlist; while a track is playing, browsing another tab does not replace the latched playback queue. Each tab is one outlined rectangle with its left-aligned title on the left and an unframed `X` on the right; titles shrink and end in an ellipsis glyph when space is limited. Tabs use the shared auto-resize easing to slide open when added and slide shut when closed. Dragging a tab into a neighbor triggers the live swap after the pointer moves at most two LCD dots into that tab from the direction of travel; neighboring tabs ease into their new slots while the pointer is held, and changing direction retargets from their current positions. Releasing the drag eases the tab strip into the committed order, which persists in the native playlist snapshot. `[+]` duplicates the selected playlist in a new tab. One empty playlist remains available, and up to 64 playlist snapshots persist through ViewBoy's native preference store. Favorites and Recent are ordinary tabs sourced from the shared favorite and playback-history stores. Opening Favorites starts with no playlist rows selected; selecting a row or using the normal range-selection gestures selects tracks. Command-1 through Command-9 select the corresponding playlist tab.

The table can show the numbered `#`, favorite, file, title, game, artist, system, path, and length columns. Playlist text rows are glyph-height; **Text Line Gap** alone sets the blank space between playlist and sidebar rows. The single selection band extends one LCD dot above and below its selected text row; selected secondary rows remain shaded as part of multi-selection. Clicking in a line gap selects the closest adjacent row, with exact ties going to the preceding row. **UI Chrome Gap** controls the separation below headings and between playlist columns. UI Button Pad does not add vertical space to playlist text. The first `#` column is fixed, numbered to fit the list, and numbers each displayed row. The favorite column is labeled `FAV` and shows the shared square checkbox, outlined when off and filled when on; clicking flips it around its vertical axis and updates the shared favorite store. Right-click any table header to show or hide File, Game, Artist, Path, and Date/Time. Options exposes the same visibility controls as an unframed square-checkbox list under Library > Playlist Columns. Auto-Hide Empty Columns hides enabled metadata columns with no values in the active playlist. Every enabled column remains present in a horizontally scrollable viewport; trackpad horizontal scroll, Shift+wheel, and Shift+Left/Right move it without a decorative bottom scrollbar. Drag header cells to reorder columns; moving the pointer at most two LCD dots into a neighbor triggers the live swap and animates surrounding headers into their slots. The easing continues during the held drag and retargets from current positions when direction changes. The numbered `#` column remains pinned. Column order is remembered in local display preferences. When Auto-size Columns is enabled, metadata widths fit their headings and available values within their column caps. Header and row widths ease together when the set changes.

Options reuses the app's sidebar and right content area, with a compact navigation width that fits the six icons. The sidebar action row and page links occupy the library pane; the active option page replaces the playlist table in the adjacent pane. The transport toolbar and playback footer stay visible. Display uses two columns in wide panes and stacks its cards in narrow panes, retaining the clipped scrolling viewport. Each Display section uses a full card with a shared filled title bar and enclosing outline. Options and the main screen share Layout Spacing: Button Pad changes control insets and heights, UI Gap changes pane/card insets and chrome gaps, and Line Gap changes text-row and page-link spacing. Reset Spacing restores 4/4/1 dots. Library > Playlist Columns uses an unframed square-checkbox list. UI Button Pad, UI Chrome Gap, and Text Line Gap are the only adjustable spacing settings; each ranges from one to eight LCD dots, with defaults four, four, and one. UI Button Pad sets control insets and standard row height; it does not alter the fixed eight-pixel screen inset or text-row height. UI Chrome Gap sets interface spacing and playlist-column spacing. Text Line Gap controls both text panes and does not inherit chrome gaps. Spacing changes animate with the shared duration and easing, and readouts stay integer-width. Sidebar actions use equal square hit areas and centered icons, and its search field follows the shared control height, padding, and chrome gap. The quiet app footer shows the active file path on the left and a right-aligned elapsed/song/playlist clock; song and playlist durations include Long Play time and fade when Long Play applies.

The Options screen uses page links grouped by ViewBoy and VGMBoy, alphabetical within each group, beside one scrolling content pane. The shared SB2 timing curve drives its shaded page marker and top-down screen transition. The gear, Escape or Command-comma returns to the library. Database shows catalog and archive-cache status and actions. Audio has ten aligned EQ bands: inline gauges in wider panes and a full-width gauge beneath each numeric row in narrow panes. The minus/plus controls stay together, and numeric readouts share a reserved width. Volume places its numeric controls above a full-width gauge. EQ keeps 25 gain settings from flat 0 to +12 dB in 0.5 dB steps. Zero is empty and maximum fills the final track pixel. Step changes animate gain and readout together; dragging previews directly, commits on release and restores on cancellation.

The Display page combines pixel method, editable colors, Contrast Boost and screen profile. LCD uses four tinted tones. Direct uses two endpoints, and 8/16 use grayscale ramps. Contrast Boost ranges from zero through 100 percent in ten-percent steps. The two independently authored fonts remain Micro 3x5 and Standard 5x7. LCD dot size remains 2 through 6 device pixels, default 3. New installations enable Pixel Matrix Gaps with the centered STN component aperture; the optional 1 PX aperture retains the old right/bottom gutters. An explicitly saved matrix-off choice is preserved.

BG and PIXEL accept three- or six-digit hex with or without `#`, space- or comma-separated RGB channel values, CSS color names, and supported CSS color functions. ViewBoy keeps the entered text (including names such as `rebeccapurple`) and stores its resolved RGB value separately for rendering. Enter applies a valid value and Escape cancels. At zero Contrast Boost, Direct previews the two exact endpoints twice; grayscale methods preview every available step and mark the selected text and background tones. Tone selections and method persist with display preferences.

This is a configurable interface grid, not a calibrated original Game Boy panel. Nintendo specifies a 160x144, four-shade STN matrix; ViewBoy remains responsive to window size. The STN aperture uses the 0.39/0.43 dot-to-pitch ratio from a Displaytech 128128A component specification. Current emulation covers aperture and tone mapping; measured reflectance, viewing-angle response, crosstalk, liquid-crystal timing and aging remain outside the implemented model. Sources and next stages are in [the LCD plan](../plans/lcd-emulation.md).

Each logical dot remains one square device-pixel cell. Pixel method, Contrast Boost and color changes preserve the selected aperture and cell pitch. STN integrates fractional coverage in linear light, while 1 PX preserves whole-pixel gutters. Matrix enablement is an independent persistent setting. One Motion setting controls animation enablement and duration across selection, disclosure, column widths, tab reorder, EQ, spacing, scrolling, and Options. Its single draggable FPS cap control accepts any integer from 30 to 240 and defaults to 60; arrow keys adjust it by one, Shift-arrow by ten, and Home/End select the limits. The cap is shared by every animation. requestAnimationFrame timestamps pace Canvas updates; actual presentation also depends on display refresh and WKWebView compositing.

The toolbar's eight controls use one shared builder and equal hit boxes. The four mode buttons use the same darker selected fill when active; their text length and current state can make them look different from the transport buttons. Previous and Next share the symbol-font glyph treatment, with `<<` intentionally aligned just inside the leading edge and `>>` centered. They still use the same button border, height, and width allocation as the other six controls.

Click the sidebar toolbar to switch Library/Path modes, open Favorites or Recent, fold or unfold all groups, or open Options. The custom pixel icons are independent of the selected text font. Queue is available from **View > Playback Queue**; catalog reload is in **Options > Database**; local paths open from the native File menu or Command-O. Fold All/Unfold All stays in the toolbar and works while Search filters the tree. Click a tree row to expand or fold a Path folder or select a game/file. Right-click a game, system, Path folder, or file for **Play Now** (replace the active playlist and start its first track) or **Enqueue** (append its tracks to the active playlist). Click a playlist row to select it; clicks in the blank Text Line Gap select the nearest row. Command-click toggles rows, Shift-click selects the inclusive range, Command-A selects all, and Escape or clicking empty playlist space clears selection. Double-click a playlist row or press Enter to play the selected playlist track. If the last selected item is in the sidebar, Enter runs **Play Now** for that game, system, Path folder, or file. Click a header to sort and right-click it to open the LCD column visibility menu. Command-1 through Command-9 select playlist tabs; Command-Shift-F opens Favorites in its tab; Command-Shift-H opens Recent in its tab; Command-comma toggles Options; Command-W closes the current playlist tab; Command-Q quits ViewBoy. Path, Console, and Disk Path views use their sidebar buttons or the View menu, Command-T duplicates a playlist in a tab. F7/F8/F9 invoke Previous/Play-Pause/Next. Arrow keys move selection (Shift extends the range), and Space toggles playback.
