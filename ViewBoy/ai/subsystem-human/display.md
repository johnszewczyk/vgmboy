# Display

ViewBoy uses one responsive LCD canvas for the library, playlist, options, and playback status. Yoga lays out the screen; a four-shade framebuffer paints every border, selection, control, and bitmap glyph. Three flat grey Game Boy membrane lines frame the LCD.

The main screen has two centered toolbar rows inside a half-width wrapper. Previous, Play/Pause, Next, and Stop fill equal shares of the first row; Long Play, Repeat One, Playlist Random, and Library Random fill the second. Options is in the sidebar action row, and both playback rows disappear while Options is open. The sidebar has no section banners: its pixel-rendered search field and Library, Path, Queue, Favorites, Open, Sync, and Options controls lead directly into catalog content. Clicking Search Library focuses and highlights the field, shows a blinking bitmap `|` cursor, and typing filters catalog game/system names or catalog paths; Escape clears the query, and a second Escape leaves search. Library groups games by system. Path lists indexed root folders and their folders/files; click a folder to expand or collapse it, double-click to load its tracks, and click a file to load its indexed tracks. The Path selection is remembered in local display preferences. The tree viewport clips and scrolls rows without resizing the sidebar or shifting the playlist pane. Wheel scrolling follows fractional LCD-dot deltas, so it can stop between rows. Bitmap `>` disclosure glyphs rotate in place as rows fold or unfold, using the shared auto-resize easing. Sidebar text rows are glyph-height; Sidebar Line Gap alone sets the blank space between sibling and nested rows, independent of UI Gap. Selecting a game or path loads tracks from the read-only catalog bridge. Queue shows the active playback list, or the browsed playlist before playback starts. Favorites and History use the shared stores. Sidebar and playlist content fills the available pane height without framed status footers.

The track pane begins with playlist tabs, followed by centered column headings. It has no separate catalog or queue title row. Selecting a game in the sidebar opens or reuses a named tab containing that game's tracks. Selecting a tab makes its list the visible playlist; while a track is playing, browsing another tab does not replace the latched playback queue. Each tab is one outlined rectangle with its left-aligned title on the left and an unframed `X` on the right; titles shrink and end in an ellipsis glyph when space is limited. Tabs use the shared auto-resize easing to slide open when added and slide shut when closed. Drag a tab to reorder it; neighboring tabs push into their new slots immediately while dragging, and the final order persists in the native playlist snapshot. `[+]` duplicates the selected playlist in a new tab. One empty playlist remains available, and up to 64 playlist snapshots persist through ViewBoy's native preference store. The Favorites view uses the shared favorite projection and hides playlist tabs.

The table can show the numbered `#`, favorite, file, title, game, artist, system, path, length, and size columns. Playlist text rows are glyph-height; Playlist Line Gap alone sets the blank space between track rows, while UI Gap controls the separation below the headings. Control Padding adds no vertical space to playlist text. The first `#` column is fixed, numbered to fit the list, and numbers each displayed row. The favorite column is labeled `FAV` and shows `[x]` or `[]`; clicking its cell updates the shared favorite store. Right-click any table header to show or hide File, Game, Artist, Path, and Size. Options exposes the same visibility controls. Every enabled column remains present in a horizontally scrollable viewport; trackpad horizontal scroll, Shift+wheel, Shift+Left/Right, and the bottom scrollbar move it. Drag header cells to reorder columns; neighboring headings push into their new slots immediately while dragging, and `#` remains pinned. Column order is remembered in local display preferences. When Auto-size Columns is enabled, metadata widths fit their headings and available values within their column caps. Header and row widths ease together when the set changes.

Buttons, outlined choices, option rows, pane headings, tab frames, and playlist headers share a font-derived row height and the same text inset. The Interface page adjusts Control Padding, UI Gap, Sidebar Line Gap, Playlist Line Gap, and Playlist Gap independently, in one-dot increments. Control Padding sets text insets and vertical breathing room on controls and option rows; it does not add vertical padding to sidebar or playlist text rows. UI Gap sets surrounding interface spacing, including the sidebar toolbar-to-tree gap, gaps between tabs and playlist headings, the gap below playlist headings, and group and pane insets. It does not change line spacing in either text list. Sidebar Line Gap and Playlist Line Gap independently set the blank dots between sidebar and playlist text rows. Playlist Gap sets horizontal spacing shared by playlist column headings and track cells. Spacing changes animate with the shared resize duration and easing; readouts display whole-dot values throughout the transition. Sidebar navigation buttons share their available width, and its search field follows the same control height, border, padding, and gap. Library and playlist panes have no in-frame status footer; Options retains its outlined footer readouts.

The Options screen uses a vertical alphabetized table of contents and one large content pane. Opening it moves the current screen down while Options rolls in from the top; Back reverses that motion. Both directions use the shared resize duration, easing, and 60-frame-per-second cap. Its pages are Audio, Database, Display, Interface, Library, Methods, Playback, Theme, and Transport. Database shows the catalog location/schema/count, reloads the catalog projection, and exposes archive-cache location, usage, enablement, size limit, clear, and Finder actions. Audio presents ten horizontal equalizer bars, each at least 100 LCD dots wide and otherwise filling the pane. Every band uses the same label width, slider width and height, value width, horizontal inset, and vertical spacing. The `[-]`/`[+]` pairs sit together before each EQ gauge and before the Volume gauge. Each EQ bar selects one of 25 gain values from flat 0 to +12 dB in 0.5 dB increments and sends changes through the native audio preference path. The four-shade bar fill grows like a level gauge toward the selected boost; its 25 tick fins are evenly spaced, and the numeric gain readout animates with the fill using the shared app easing and frame cap.

The Micro 3×5 and Standard 5×7 bitmap fonts are independently authored and switchable on the Display page. Both fonts use uppercase glyphs only; lowercase labels are normalized to uppercase before pixels are drawn. The Theme page selects GameBoy or NightBoy palettes and standard or high-contrast ink. Both palettes map the same four framebuffer shades; High Contrast changes tone 0 (`#333333` for GameBoy and brighter silver for NightBoy) without adding a fifth display value. NightBoy also changes the narrow membrane lines to a dark-purple surround with silver details.

Each logical dot occupies a 3×3 device-pixel cell with a 2×2 shaded face and an unlit LCD seam. The grid scales with available space and device-pixel ratio, independent of the Game Boy's native 160×144 resolution. Selection, disclosure, and column-width animation frames are capped at an average of 60 updates per second. The frame gate advances on nominal 60 Hz intervals rather than resetting to each display refresh callback, preserving the cadence on 90 Hz and 144 Hz displays as well as 60 Hz displays. Timestamp simulations cover 60, 90, 120, and 144 Hz; actual presentation timing in WKWebView still depends on macOS compositing.

The renderer models the visible dot matrix and four quantized LCD tones, not the Game Boy's controller or electrical drive circuitry. Circuit-level simulation would not improve this app's screen output. Future authenticity work should focus on measurable optical traits such as dot aperture, cell edge, subtle viewing-angle shading, and restrained pixel response or ghosting. Keep any response effect frame-delta based and optional so static text remains crisp and canvas redraws stay inexpensive.

Click the sidebar toolbar to switch Library/Path modes, open a local path, or reload the catalog; click a tree row to expand a Path folder or select a game/file. Click a track to select it, double-click to play it, and click a header to sort. Right-click a header to open the LCD column visibility menu. Command-1/2/3 switch to Path, Console, and Disk Path views; Command-Shift-D opens Favorites; Command-Shift-H opens Playback History; Command-comma opens Options; Command-W closes the current playlist tab; Command-Q quits ViewBoy. Command-Option-1 through Command-Option-9 select playlist tabs, Command-T duplicates a playlist in a tab, and Command-O opens a local path. F7/F8/F9 invoke Previous/Play-Pause/Next. Arrow keys move selection, Enter plays, and Space toggles playback.
