# System and Game Sidebar

The LCD sidebar has six equal square bitmap actions for Console/Library, Path, Favorites, Recent, Fold/Unfold Tree, and Options. Every action uses pixel artwork centered by its lit bounds in the same fixed 13-dot button, independent of the selected text font. Queue is available from View > Playback Queue; catalog reload is in Options > Database; local path opening remains in the native File menu and Command-O. Console mode groups the read-only catalog's games by system. Selecting a system opens or closes its game rows; child game text sits one bitmap glyph advance beyond its parent text. Selecting a game loads its tracks into the main pane. Path mode renders `databaseFileTree` and uses `databaseFolderTracks`/`databaseFileTracks`; single-click folders fold or unfold, double-click loads a folder, and selecting a file loads that file's indexed tracks. Root chevron ink aligns with the leading edge of the search and toolbar controls; nested disclosure markers and text step inward by one bitmap glyph advance per depth. Text leading and trailing insets are separate: charge depth only to the left and reserve only the configured control pad on the right. Hover metadata preserves the full source name. Folder and file labels align to the same label column at each depth. Chevron cells share the row text's vertical alignment. Top-level Path folders start expanded on first use, then fold and persist like nested folders. The tree action applies Fold All / Unfold All to every system group in Console mode or every expandable Path node in Path mode, including while Search filters the tree. Bulk and individual disclosures share the canonical animation timing and FPS gate. Reload refreshes the shared catalog database and re-queries its projection; the app footer displays reload progress over the active file path. Right-clicking a system, game, Path folder, or file offers Play Now and Enqueue. Play Now replaces the active tab's playlist and starts the first returned track. Enqueue adds only tracks not already in the active playlist; if that tab owns playback, the additions extend its playback queue without replacing the current track. Persist expanded Path nodes and the sidebar mode as display/native preferences respectively.

`CatalogBrowserCore` reduces individual and all-system disclosure plus game selection through the native `databaseGroupState` bridge. JavaScript keeps the returned expansion and selection state for rendering. Path-node disclosure state remains in ViewBoy's display preferences. Both group types animate from per-node progress values so nested row stacks clip away fully at completion; do not force root paths open after their saved state has been cleared. Disclosure follows the shared motion duration and FPS gate. `CatalogReader` supplies catalog games, tracks, and the indexed file tree; the UI does not scan source folders or write catalog data.

The native `databaseGames` projection returns `CatalogBrowserProjection.groups`
with stable game IDs and canonical group names. Search uses the shared
`CatalogBrowserProjection.search` and `CatalogFileSearchIndex` policies; the
Canvas adapter filters by returned IDs and file identities. Keep grouping,
fallback labels, ordering, and matching out of the renderer.

The Library pane fits its six icon buttons and configured UI gaps as a minimum. Its adaptive default keeps the previous layout-unit minimum and grows to 30 percent of wider framebuffers. A six-dot dotted splitter previews width changes locally; release saves a window fraction bounded to 15–65 percent, cancellation restores the starting value, and double-click clears the override. The icon minimum still wins when a small window cannot fit the requested fraction. Options uses its compact icon-width navigation pane without a splitter. Pane width is a fixed flex basis during layout, with growth/shrink disabled; tree expansion cannot resize it. The tree viewport takes remaining height (`flexBasis: 0`, `minHeight: 0`) and clips row content. UI Gap is converted from logical dots to Yoga units exactly once. Keep search and actions directly above the tree; Options alone adds a filled navigation header. Pane bottoms remain content areas; the shared footer owns file/time readouts. Resizing changes only presentation preferences and never changes the catalog, selection or playback.

View > Playback Queue displays the active playback list, falling back to the browsed playlist before playback starts. Favorites reads and updates the shared `FavoriteStoreCore`. The native File menu and Command-O invoke the local path chooser and folder projection; they are separate from Path mode, which browses the catalog's indexed paths.
