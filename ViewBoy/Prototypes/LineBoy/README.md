# LineBoy prototype

Standalone visual mockup for a monochrome DOS-style ViewBoy sibling. It uses
black and gray surfaces, reverse-video command blocks, outline controls, and a
subtle scanline overlay. Track and toolbar controls are local presentation
interactions only; this prototype is not wired to the catalog or playback
bridge.

Open `index.html` in a browser, or serve this directory locally with:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory ViewBoy/Prototypes/LineBoy
```
