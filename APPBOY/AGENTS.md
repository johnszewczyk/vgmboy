In the `Code/` workspace, start with [DocMan](../../DocMan/AGENTS.md) and its
[`project-info.md`](../../DocMan/project-info.md), then read the VGMMan family
route at [`../AGENTS.md`](../AGENTS.md) and

[`ai/AGENTS.md`](ai/AGENTS.md), [`ai/project-info.md`](ai/project-info.md), and
the focused APPBOY note routed by the task.

APPBOY is the native iOS player package in the VGMMan family. It translates
SB2's dark obsidian/cyan pixel-style presentation, typography, motion language,
and trusted WebKit request/event bridge to responsive iPhone and iPad
viewports, with its own Swift package, preference namespace, background audio
coordinator, and sideload `.ipa` release boundary. Do not import or clone
SBONLINE Django templates, hosted account/social chrome, or older mobile web
prototypes.

Run Git commands from the VGMMan family root (`../`); do not initialize a
nested Git repository inside `APPBOY/`.
